# **Demás enfermedades – Mujeres** 

En las mujeres el comportamiento de las muertes por las demás causas se presentó así: en primer lugar, el aporte fue para las enfermedades crónicas de las vías respiratorias sin casos al 2019; el segundo lugar fue para el resto de las de las enfermedades también sin casos al 2019; el tercer lugar es para el resto de las enfermedades del sistema digestivo sin casos de muerte desde el 2016.
