# **Programa 4.5.4 Valparaíso Territorio Ordenado.** 

# **Responsable: Secretaría de Planeación y Desarrollo Territorial** 

**Objetivo:** Realizar ejercicios de control urbanístico para orientar el desarrollo ordenado del territorio en la implementación del EOT, brindando las herramientas sensibilización y socialización que permitan lograr la consecución de este objetivo. 

**Descripción:** Este programa tiene como apuesta fundamental, supervisar y orientar el desarrollo del municipio de acuerdo con el Estudio de Ordenamiento Territorial (EOT). Para hacerlo posible, se desarrollarán diversas acciones, entre las que se incluyen inspecciones regulares de obras de construcción, revisión y aprobación de proyectos de urbanización, edificación y subdivisión, así como el control de ocupaciones informales o ilegales del espacio público y del suelo urbano. Además, se implementarán medidas correctivas y sanciones en casos de incumplimiento de las regulaciones urbanísticas. 

A la luz de este programa se desea promover el uso adecuado del suelo de acuerdo con el EOT, mediante la realización de campañas de sensibilización dirigidas a la comunidad. También, se busca llevar a cabo la gestión para la actualización catastral de la zona urbana del municipio, con el apoyo de entidades o instituciones de carácter regional o nacional, con el interés de aportar a una gestión territorial eficiente y sostenible en Valparaíso.
