# Diagnóstico territorial y parte estratégica 

## PLAN DE GOBIERNO 2024-2027: “EN MONTEBELLO, YO CREO” 

Desde el primer paso que dimos para afrontar este reto y poder ayudar a la comunidad Montebellense, decidimos recorrer todo el territorio para escuchar de primera mano las necesidades de las personas en cada una de las veredas y el corregimiento del municipio. A partir de estas experiencias, construimos nuestro Plan de Gobierno en colaboración con las comunidades, a través de encuentros para creer. Este proceso fue un esfuerzo conjunto entre la ciudadanía y el equipo de colaboradores, que llevó a la identificación de cinco ejes principales para abordar esas necesidades. 

Para responder a estas demandas, desarrollamos programas y estrategias para recuperar la ruta de Montebello, y en el siguiente gráfico mostramos estas estrategias que construimos con las personas, las cuales están articuladas con el Plan de Desarrollo Territorial. 

Desde ese punto de partida, hemos definido acciones para fortalecer la institucionalidad y asegurar una integración coherente entre el plan de gobierno y el plan de desarrollo. Los programas incluidos en el plan de desarrollo están diseñados para proporcionar bienes y servicios a la comunidad, con el objetivo de cerrar brechas y construir una sociedad equitativa e inclusiva.
