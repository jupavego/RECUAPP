# **Producto Interno Bruto Municipal - PIB** 

La información sobre el PIB de Cañasgordas se presenta como un referente para mostrar cómo fue la estructura productiva de la economía local durante el año 2020 para tener una idea de cuánto produce el municipio. Es posible que el comportamiento del PIB y la producción por sectores siga igual, o que haya variado para el año 2023. La fuente oficial es el Anuario estadístico de Antioquia publicado por la Gobernación.

# **Articulaciones Especiales del Plan de Desarrollo** 

El plan de desarrollo de Cañasgordas tendrá articulaciones especiales para gestionar programas y proyectos aunando esfuerzos con los niveles de gobiernos del orden nacional, departamental y entidades privadas. De esta manera se tendrán presente planes y políticas públicas.
