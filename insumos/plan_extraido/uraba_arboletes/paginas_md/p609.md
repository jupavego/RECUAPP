# **Demás causas** 

Dentro de las demás causas de mortalidad en los hombres de Arboletes, para el año 2021, se encuentra como evento principal la  Diabetes mellitus, presentando 16.2 muertes por cada 100 mil hombres, Seguido de este evento, se encuentran el Resto de enfermedades del sistema digestivo con un comportamiento variable durante el periodo de estudio, el cual presenta un aumento para el año 2021, alcanzando una tasa de 12.4 muertes por cada  100 mil hombres, el cual está relacionado con diversos factores de riesgo y determinantes, tanto de hábitos alimenticios, culturales, laborales y ambientales. Por esta razón, se invita a fortalecer los programas que apuntan a la promoción de actividades para atender factores relacionados la alimentación adecuada, entre otros. Las Enfermedades crónicas de las vías respiratorias inferiores, es la tercera causa de muerte con 12.4 muertes por cada 100 mil hombres para el año 2021, pudiendo ser las causas de estas muertes, las secuelas del Covid19.
